# TrendIQ Landing Page

Official public landing page for TrendIQ.

TrendIQ is an early-stage consumer product intelligence platform that helps people understand which products, apps, and emerging trends are gaining momentum.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/` and can be deployed to Vercel or another static hosting provider.

## Contact Email

The page uses `VITE_TRENDIQ_CONTACT_EMAIL` when configured. If no value is provided, it displays a neutral placeholder contact email.
